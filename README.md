## 🚀 Быстрый старт

### 1. Подготовка кода
Откройте файл `index.js`, замените `ВАШ_ТОКЕН` и `ВАШ_ID` на ваш реальный токен и ID доступа ВКонтакте:

```javascript
const TOKEN = 'ВАШ_ТОКЕН'; // Вставьте ваш токен здесь
```
```javascript
const userId = "ВАШ_ID"; // Вставьте ваш ID здесь
```
- **Как найти ТОКЕН и ID смотрите ниже!**

### 2. Архивирование проекта
Заархивируйте папку `vk-nowplaying` со следующими файлами:
- `index.js`
- `package.json`
- `README.md`

### 3. Развертывание на Render

1. Перейдите на [render.com](https://render.com)
2. Создайте **New Web Service**
3. Выберите опцию **Upload Zip** и загрузите архив
4. Выберите окружение: **Node.js**
5. Установите команду запуска: 
   ```
   npm start
   ```

### 4. Получение URL сервиса
После успешного развертывания Render предоставит вам URL вида:
```
https://vk-nowplaying.onrender.com/
```

### 5. Интеграция в StreamElements

В StreamElements создайте новую команду:
```
!addcommand !трек $(customapi https://vk-nowplaying.onrender.com/)
```

Теперь при вводе команды `!трек` в чате будет отображаться текущий трек! 🎶

## 📝 Переменные окружения

Убедитесь, что токен ВКонтакте безопасно хранится и не публикуется в репозитории.

## 📚 Дополнительно

### Как найти токен:

-  Для получения токена ВКонтакте посетите [dev.vk.com](https://oauth.vk.com/authorize?client_id=2685278&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=status&response_type=token&v=5.131)
-  Далее ввойдите в свой профиль
-  После этого вас перебросит на похожую страницу -> (https://oauth.vk.com/blank.html#access_token=vk1.a.xxxxx&expires_in=0&user_id=...)
-  В строке адреса скопируйте "vk1.a.xxxxx", всё что находится между символами "=" и "&" ! 
-  Это и будет ваш токен.

### Как найти ID:

-  Для **ID** в конце той же строки найдите - **"user_id=123456789"**
-  Обычно это 9 цифр, и у всех они разные!
-  Это и будет ваш ID.

# VK Now Playing 🎵

Инструмент для отображения текущей трека ВКонтакте в StreamElements.

## 🚀 Быстрый старт

### 1. Подготовка кода
Откройте файл `index.js` и замените `ВАШ_ТОКЕН` на ваш реальный токен доступа ВКонтакте:

```javascript
const TOKEN = 'ВАШ_ТОКЕН'; // Вставьте ваш токен здесь
```

### 2. Архивирование проекта
Заархивируйте папку `vk-nowplaying` со следующими файлами:
- `index.js`
- `package.json`
- `README.md`

### 3. Развертывание на Render

1. Перейдите на [render.com](https://render.com)
2. Создайте **New Web Service**
3. Выберите опцию **Upload Zip** и загрузите архив
4. Выберите окружение: **Node.js**
5. Установите команду запуска: 
   ```
npm start
   ```

### 4. Получение URL сервиса
После успешного развертывания Render предоставит вам URL вида:
```
https://vk-nowplaying.onrender.com/
```

### 5. Интеграция в StreamElements

В StreamElements создайте новую команду:
```
!addcommand !трек $(customapi https://vk-nowplaying.onrender.com/)
```

Теперь при вводе команды `!трек` в чате будет отображаться текущий трек! 🎶

## 📝 Переменные окружения

Убедитесь, что токен ВКонтакте безопасно хранится и не публикуется в репозитории.

## 🔧 Требования

- Node.js 14+
- npm
- Токен доступа API ВКонтакте

## 📚 Дополнительно

Для получения токена ВКонтакте посетите [dev.vk.com](https://dev.vk.com)

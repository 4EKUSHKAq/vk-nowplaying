## 🚀 Быстрый старт

### 1. Форк или копия проекта

Сделайте fork этого репозитория к себе на GitHub или используйте его как шаблон для своего проекта.

Название репозитория можно оставить без изменений.

### 2. Развертывание на Render

1. Перейдите на [render.com](https://render.com)
2. Создайте **New Web Service**
3. Подключите ваш репозиторий **GitHub**
4. Убедитесь, что Render определил окружение **Node.js**
5. Установите команду сборки:
   ```
   npm install
   ```
6. Установите команду запуска:
   ```
   npm start
   ```

### 3. Добавление переменных окружения в Render

В настройках сервиса Render откройте раздел **Environment** и добавьте:

```text
VK_TOKEN = ВАШ_ТОКЕН
VK_USER_ID = ВАШ_ID
```
<img width="1300" height="400" alt="Screenshot_1" src="https://github.com/user-attachments/assets/482a1895-727a-4908-b718-b5ad444779e9" />

- `VK_TOKEN` — ваш токен доступа ВКонтакте
- `VK_USER_ID` — ваш ID профиля ВКонтакте

После этого выполните повторный деплой сервиса.

### 4. Получение URL сервиса

После успешного развертывания Render предоставит вам **уникальный URL вашего сервиса**.

Пример:

```text
https://ваш-сервис.onrender.com/
```

Этот адрес у каждого пользователя будет **свой**, даже если название репозитория одинаковое.

### 5. Интеграция в StreamElements

- #### В StreamElements создайте новую команду, используя **свой URL из Render**:
  
<img width="800" height="300" alt="Screenshot_2" src="https://github.com/user-attachments/assets/2c19def0-0ea7-4c30-a07b-723adc7c7bab" />

- #### Если бот StreamElements уже добавлен на ваш канал, просто измените ссылку на свою и отправьте эту команду в чат:
```
   !addcommand !трек $(customapi https://ваш-сервис.onrender.com/)
```


Теперь при вводе команды `!трек` в чате будет отображаться текущий трек! 🎶


## 📝 Переменные окружения

Убедитесь, что токен ВКонтакте хранится безопасно и не публикуется в репозитории.

Используемые переменные:

- `VK_TOKEN` — токен доступа ВКонтакте
- `VK_USER_ID` — ID вашего профиля ВКонтакте

## 🔧 Требования

- Аккаунт GitHub
- Аккаунт Render
- Токен доступа API ВКонтакте
- ID профиля ВКонтакте
- Аккаунт StreamElements

## 📚 Дополнительно

### Как найти токен:

-  Для получения токена ВКонтакте посетите [vkhost.github.io](https://vkhost.github.io/)
-  Далее из списка выберете **Kate Mobile**
-  После этого вас перебросит на страницу авторизации, ввойдите в тот аккаунт, с которого будет включаться музыка
-  После авторизации откроется страница, в адресной строке которой будет токен вида - "vk1.a.xxxxx", скопируйте всё что находится между символами "=" и "&" ! 

-  Это и будет ваш токен.

### Как найти ID:

-  Для **ID** в конце той же строки найдите - **"user_id=123456789"**
-  Обычно это 9 цифр, и у всех они разные!

-  Это и будет ваш ID.

### Если не работает:

- Проверьте правильность `VK_TOKEN`
- Проверьте правильность `VK_USER_ID`
- Убедитесь, что после изменения переменных выполнен **Redeploy** на Render

- Также убедитесь что у вас включена функция трансляции музыки в статус!↘️
